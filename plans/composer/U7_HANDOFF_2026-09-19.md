### Two things found while building it (both have gates now)

1. **`[General]` is a reserved section in Qt's ini format** — keys stored under
   `general/x` are written into it and read back as `x`, i.e. *lost across a
   restart*. Invisible in-process, because `QSettings` serves a typed cache to
   every instance over the same file; caught only by a test that writes ini
   text by hand (`ValuesWrittenAsIniTextComeBackWithTheirTypes`). Every key is
   stored under a `preferences/` prefix now; `appearance/mode` keeps its old
   spelling so an earlier choice is honoured.
2. **Exclusive radio buttons cannot be cleared with `setChecked(false)`** —
   reverting the dialog from Dark to System left Dark lit. Fixed by checking the
   one that applies; mutation D4 restores the bug.

### Deliberate narrowings

- No migration of the old `recentCompositions/showWelcome` key (the welcome flag
  now lives at `preferences/general/showWelcomeOnStartUp`). A user who had unticked
  it sees the page once more.
- No gate for the 3D background colour: `QRhiWidget` cannot create a device under
  the offscreen platform (C3a, D31), so `SceneView` is not renderable in a test.
  Verified by eye (§4 below).
- `kClickSlopPixels` in `mapcanvas.cpp` was an **unused** duplicate of the
  constant being migrated; removed with the migration rather than left as a
  decoy. `kSnapPixels` left `domainsnap.h` for the same reason.
- Colours are stored as `#aarrggbb` text so the ini is hand-editable; the read
  path coerces them back.

## 4. Look at it

Captures, for `artifacts/` as the earlier phases did:

```bash
build/darwin/composer_screenshot artifacts/composer-preferences.png --preferences
build/darwin/composer_screenshot artifacts/composer-preferences-components.png --preferences Components
build/darwin/composer_screenshot artifacts/composer-preferences-dark.png --preferences --dark
```

Then launch `build/darwin/HydroCoupleComposer.app` and walk this list. Each line
is something a user can reach; each has a visible consequence.

1. **View ▸ Appearance ▸ Preferences…** (or ⌘,) opens the dialog; the ribbon's
   *View* tab shows a *Settings* group with a *Preferences* face carrying a gear.
2. **Appearance page:** choose *Dark*, press *Apply* — the window re-themes
   *while the dialog is open*, and the ribbon's *Dark* face lights. Press the
   ribbon's *Light* face — reopen the dialog: *Light* is selected. Quit and
   relaunch: still Light.
3. **General page:** untick *Show the welcome page on start up*, OK. The welcome
   tab's own checkbox is now unticked without the page being rebuilt. Relaunch:
   the window opens on *Composition*.
4. **Components page:** *Add…* the plugin directory you normally *Load
   Directory…* from; OK. The component palette fills immediately (search paths
   are applied on change). Relaunch: it fills on start-up with no menu action.
   Conversely, use *Components ▸ Load Directory…*: reopen the dialog and the
   directory is listed.
5. **Selection page:** set *Selection colour* to red and *Pick tolerance* to
   30 px; OK. On the map, click 20 px beside a feature: it selects, outlined in
   red; the *3D* tab shows the same feature in red (the colour is baked into the
   vertices, so this proves the scene rebuilt on the change). Set *Drag
   threshold* to 0: a click that twitches by a pixel pans instead of picking.
6. **Map page:** set the default CRS to `EPSG:26912` (type it, or *Choose…*
   opens the same catalogue as *Map ▸ Coordinate System*); relaunch; the status
   bar's CRS button reads `EPSG:26912`. Type `EPSG:999999` — relaunch falls back
   to Web Mercator rather than to no CRS.
7. **3D View page:** set the background to white, *Apply* — the 3D view
   repaints white at once. Set the default projection to *Orthographic* and
   exaggeration to 3; relaunch; the 3D tab opens orthographic, stretched.
8. **Reset to defaults** on any page: every page's widgets return to the
   defaults immediately and the window follows (theme back to System, colour
   back to cyan) — it is applied at once, not staged behind OK.
9. **Cancel** after editing every page changes nothing anywhere.
10. Open `~/Library/Preferences/org.hydrocouple.HydroCoupleComposer.plist` (or
    `defaults read org.hydrocouple.HydroCoupleComposer` — the domain Qt derives
    from the organisation domain `hydrocouple.org` and the application name,
    and since 2026-09-19 also the bundle's identifier, so Cocoa's window and
    panel state sits in the same plist): keys sit under
    `preferences.<group>.<name>`; colours are `#aarrggbb` strings.

If any of 1–10 does not hold, the corresponding gate in §3 is the one that
should have caught it — say which, so the gate can be fixed alongside the code.
