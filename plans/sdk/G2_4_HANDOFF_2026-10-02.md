**Reviewed.** Before shipping, a separate agent that had not seen the work
reviewed the whole change set cold. It found three wrong-result bugs the
gates missed -- an adapter fed from outside the workflow had lost its
argument gradients (a regression of the routing rewrite);
`TorchComposition` re-initializing a stateless adapter refreshed a stateful
one below it, so repeated runs drifted; a component reading its own output
through a relaxation was accepted with a wrong gradient -- and several
smaller ones (a relaxation token that threw on a negative count and lost
infinities and NaNs, stale stateless adapters after a restore, seeds on a
non-differentiable adapter silently zero, adapter tokens keyed by address
alone, a test fixture that trusted buffer shapes, and doc claims). All are
fixed, each with a gate and, for the engine and adapters, a falsifier row
(S15–S20, L4, T11 rewritten).

## 1. What changed (details in the CHANGELOGs)

### HydroCouple — interface, inside ABI 4

- `IAdaptedOutput::states()` — **pure virtual: every `IAdaptedOutput`
  implementation must add it** (empty for a stateless adapter). Inside these
  repos only the SDK's `AbstractAdaptedOutput`, the bindings' test fixture
  and the Python example's adapter implement the interface directly (all
  updated); anything out of tree (FVQual?) that does must add it too.
- `IDifferentiableAdaptedOutput::differentiableStates()`; the "stateless
  adapters only" paragraph is replaced by the state contract.
- New `ICheckpointableAdaptedOutput` (save / restore / release).
- Conventions stated: adapters are discovered by cast (no capability set);
  adapters report `bool` + `message` failures through the message alone.
- Python mirror, bindings and tests for all of the above.
- Version: `2.0.0-alpha.2` in CMake, vcpkg.json, CITATION.cff, Doxyfile,
  header `\version` tags, README, `hydrocouple.__version__` (`2.0.0a2`);
  CHANGELOG "Unreleased" → "2.0.0-alpha.2 — 2026-10-02" (adjust the date if
  you tag on another day).

### HydroCoupleSDK

- `RelaxationAdaptedOutput`: differentiable and checkpointable; **λ is read
  at every refresh** (it was latched at `initialize()`). A host that sets λ
  once before `initialize()` sees no difference.
- `DifferentiableWorkflow`: per-output cotangent routing, adapter trees
  reversed once per step, adapter tokens in every checkpoint, new refusals
  (stateful adapter not checkpointable; adapter that joined after a
  checkpoint). `StateGradient` gained `owner`/`adapter`;
  `Gradients::findState()` takes any owner (source-compatible for callers
  passing a component).
- `AbstractAdaptedOutput::states()` returns none;
  `TemporalInterpolationAdaptedOutput` exposes its sample record.
- Version `2.0.0-alpha.2`; CHANGELOG "[Unreleased] — 2.1.0" →
  "[2.0.0-alpha.2] — 2026-10-02" (2.1.0 would break the MAJOR.MINOR lockstep
  the configure step enforces).
- `LinearTransformAdaptedOutput` reads its coefficients at every refresh
  (they were latched at `initialize()`), and `TorchComposition` initializes
  no adapter (initialize() refreshed everything below it).
- After a restore, stateless adapters are refreshed, then stateful ones
  restored. New refusals: a lagged self-coupling, a stateful adapter fed
  from outside the workflow, a seed on a non-differentiable adapter.
- `verification/g2/falsify.sh`: rows S1–S20 and L4 (engine and adapters),
  E1/E4/E5/E8/T11 rewritten for the new routing.

**Every vtable that derives from `IAdaptedOutput` grew: rebuild everything
that links the SDK** (as for the `UnitDimensions` layout change of
2026-10-01).

### HydroCoupleComposer

No source change this round (it implements no adapter itself). It must be
rebuilt against the new SDK. The ABI-4 port of 2026-09-30 is still
uncommitted (`plans/composer/COMMIT_ABI4_PORT.txt`).

## 3. Not done (deliberately)

- Ontology items of the 2026-09-29 review (§5 #5, #13): held.
- Review item 11's remainder (transport collectives, input boundary role,
  `IConservationReport`): waiting for a consumer.

  its state changes shape every refresh; that belongs to a multi-rate
  phase.

  a caller chains it, as the composition gate does.

  visible to C++ through the bridge.
